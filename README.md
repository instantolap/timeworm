# 🐛 TimeWorm - frisst deine Stunden

A lightweight GTK4 time tracking application with SQLite backend.

## Features
- Project management with hourly rates (€/h)
- Start/Stop timer with system tray integration
- Manual time entry editing
- Monthly reports & export (Excel, CSV, PDF)
- Filter by project & date range
- GNOME Dock integration

## Tech Stack
- Python 3.11+
- GTK4 (via PyGObject)
- SQLite3
- openpyxl (Excel export)
- ReportLab (PDF export)

## Installation

```bash
pip install -e .
```

## Usage

```bash
timeworm
```
